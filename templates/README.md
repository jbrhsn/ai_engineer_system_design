# Templates

Reference-only files. Copy content from these into target files when authoring — never edit these originals.

| Template | Destination | Used for |
|---|---|---|
| `chapter-notes-template.md` | `[chapter]/01-*.md` – `03-*.md` (or `04-*.md` for the one dense chapter) | Standard topic notes structure (TL;DR → ELI5 → Learning Objectives → Visual Overview → Key Concepts → Implementation → Pitfalls → Definitions → Summary → Self-Check → Further Reading) |
| `interview-prep-template.md` | `[chapter]/NN-interview-prep.md` (NN = number after last topic note) | Interview-specific Q&A, STAR frames, vocabulary, red flags |
| `section-index-template.md` | `[section]/README.md` | Section overview, chapter table, study tips |
| `capstone-template.md` | `capstone/project-brief.md` | Final integrative project brief |
| `authoring-guidelines.md` | (stays in `templates/`, referenced directly) | Quality rubric and depth calibration for all authoring |

See `AGENTS.md` at the repo root for full authoring rules (Content Depth Rules 1–9, file naming, markdown style).
